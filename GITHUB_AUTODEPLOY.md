# Настройка автодеплоя из GitHub

**Сейчас:** Код загружен через `railway up` (разовая загрузка)
**Нужно:** Автоматический деплой при каждом `git push`

---

## Как переключить на GitHub

### В открытом Railway проекте:

1. Выбери свой сервис (должен быть один)
2. **Settings** → **Source**
3. Нажми **Connect Repo**
4. Выбери репозиторий: **bootchq/training-bot**
5. Branch: **main**
6. Root Directory: оставь пустым (или `/`)
7. **Connect**

**Готово!** Теперь при каждом `git push` Railway автоматически задеплоит новую версию.

---

## Проверка

После подключения GitHub:
- Railway → Deployments → должен появиться новый деплой с GitHub иконкой
- При следующем `git push` в main → автоматически запустится новый build

Если хочешь удалить код загруженный через CLI:
- Railway CLI больше не нужен для деплоя
- Можешь удалить `.railway-project-id` из проекта
