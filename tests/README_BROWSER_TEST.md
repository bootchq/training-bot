## 🔧 Как Это Работает

### Техническое Решение

**Проблема:** Telegram Web не работает с deep links через URL хэш

**Решение (Попытка 7 из 7):**
1. Открываем `https://t.me/{BOT_USERNAME}`
2. На странице t.me находим кнопку "Web Telegram"
3. Кликаем через JavaScript
4. Бот автоматически открывается в Web Telegram!

### Сохранение Сессии

Сессия Telegram сохраняется в Chrome профиле:
```
~/Library/Application Support/Google/Chrome/BotTesting/
```

**Важно:**
- Профиль создан ОДИН РАЗ
- Скопированы данные из твоего дефолтного профиля Chrome
- Сессия сохранена НАВСЕГДА - авторизация больше НЕ НУЖНА!

## 🐛 Troubleshooting

### Chrome не запускается с remote debugging

**Решение:** Убедись что Chrome полностью закрыт, затем запусти:
```bash
killall "Google Chrome"
python3 auto_browser_test.py
```

### Сессия не сохраняется

**Решение:** Запусти первый раз:
```bash
cd tests
bash start_chrome.sh
```

Авторизуйся в Telegram через QR-код. После этого закрой Chrome и запускай тест обычным способом.

### Кнопки не находятся

**Проверь скриншоты** в `screenshots/` - там будет видно что именно происходит.
