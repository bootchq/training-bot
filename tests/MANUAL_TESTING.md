## Тест 3: Онбординг — Подготовка к забегу

**Цель:** Проверить flow создания плана для забега.

### Шаги

1. После регистрации Garmin нажми "⏭ Настроить тренировки"
2. Выбери "🏁 Подготовка к забегу"
3. Выбери "⛰ Трейл"
4. Введи дистанцию: `50`
5. Выбери дни: Пн, Ср, Пт (нажми 3 раза)
6. Нажми "✅ Готово"
7. Введи время: `19:00`

### Критерии успеха

- ✅ После "Подготовка к забегу" показались типы забегов
- ✅ После "Трейл" запросили дистанцию
- ✅ После дистанции показались кнопки дней (Пн-Вс)
- ✅ Кнопки дней toggle (меняют цвет/emoji при клике)
- ✅ После "Готово" запросили время
- ✅ После времени показали завершение настройки

### Важно

- Кнопки дней должны **toggle** (нажал — выбрался, нажал снова — убрался)
- Кнопка "Готово" всегда внизу
- Время можно вводить в формате `19:00` или `1900`

## Тест 6: Кнопка Google Calendar

**Цель:** Проверить что кнопка Google Calendar работает.

### Шаги

1. После завершения онбординга ищи кнопку "📅 Google Calendar"
2. Нажми на неё
3. Проверь ответ

### Критерии успеха

- ✅ Кнопка реагирует на клик
- ✅ Показывается сообщение (либо ссылка, либо инструкция)
- ✅ НЕ зависает и НЕ падает

### Если кнопка не работает

- Это известная проблема: standalone CallbackQueryHandlers должны быть ДО ConversationHandlers
- Проверь что в `telegram_bot.py` строки с `add_handler(CallbackQueryHandler(...))` идут ПЕРЕД ConversationHandlers

## Тест 8: Валидация вводов

**Цель:** Проверить что бот корректно обрабатывает ошибки.

### Проверки

| Ввод | Ожидание | Как проверить |
|------|----------|---------------|
| Email: `invalid` | Просит ввести снова | Введи невалидный email при регистрации |
| Дистанция: `abc` | Просит ввести число | Введи текст вместо числа |
| Дистанция: `0` | Просит > 0 | Введи 0 или отрицательное |
| Время: `25:00` | Просит корректное время | Введи невалидное время |
| Время: `abc` | Просит корректное время | Введи текст вместо времени |

### Критерии успеха

- ✅ Бот не падает на невалидных вводах
- ✅ Показывает понятные ошибки

## Если что-то сломалось

### Шаг 1: Проверь логи

```bash
railway logs --tail 100
```

Ищи:
- `ERROR` — ошибки Python
- `Traceback` — стектрейсы
- `Timeout` — проблемы с API

### Шаг 2: Проверь Railway

1. Зайди на railway.app
2. Проверь что сервис `RUNNING`
3. Проверь что env переменные заполнены

### Шаг 3: Проверь Garmin API

Garmin Connect иногда падает. Проверь:
```bash
curl -I https://connect.garmin.com
```

Если 503/504 — проблема на стороне Garmin.

### Шаг 4: Локальная отладка

```bash
cd "/Users/noor/Documents/Obsidian Vault/Бот тренера/bot_trainer"
python3 src/bot/main.py
```

Смотри ошибки в консоли.
