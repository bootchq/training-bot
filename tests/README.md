# Тесты бота

## 📋 Обзор тестовых файлов

### ✅ Работающие тесты

#### 1. test_bot_logic.py
**Назначение:** Unit-тесты логики бота через mock objects

**Что тестирует:**
- Команда /start - проверяет welcome message и inline кнопки
- Команда /help - проверяет справку
- Команда /calendar - проверяет что НЕ использует OAuth

**Как запустить:**
```bash
python3 test_bot_logic.py
```

**Статус:** ✅ РАБОТАЕТ - рекомендуется для CI/CD

---

#### 2. final_check.py
**Назначение:** Проверка бота через Telegram Bot API

**Что проверяет:**
- Бот онлайн (getMe)
- Зарегистрированные команды (getMyCommands)
- Режим работы (webhook/polling)
- Описание команды /calendar (без упоминания Google OAuth)

**Как запустить:**
```bash
python3 final_check.py
```

**Требует:** TELEGRAM_BOT_TOKEN в переменных окружения или .env

**Статус:** ✅ РАБОТАЕТ

---

### 🔧 Вспомогательные скрипты

#### 3. launch_chrome.py
**Назначение:** Запускает Chrome с remote debugging и сохранённой сессией

**Что делает:**
- Запускает Chrome на порту 9222
- Использует BotTesting profile с сохранённой сессией Telegram
- Открывает Telegram Web /k/ версию

**Как запустить:**
```bash
python3 launch_chrome.py
```

**Статус:** ✅ РАБОТАЕТ - сессия сохраняется, авторизация не требуется

---

### ⚠️ Частично работающие тесты

#### 4. chrome_auto_click.py
**Назначение:** Полностью автоматический браузерный тест с кликами по кнопкам

**Что делает:**
- Открывает бота через deep link
- Отправляет /start
- Находит inline кнопки
- **Пытается кликнуть (НЕ РАБОТАЕТ - browser security блокирует callbacks)**

**Проблема:**
```
Browser error: "Not allowed to launch 'tg://resolve' because a user gesture is required"
```

**Статус:** ⚠️ ЧАСТИЧНО - кнопки находит, но клики не триггерят bot responses

---

#### 5. test_real_clicks.py
**Назначение:** Глубокая JavaScript симуляция всех событий клика

**Что пробует:**
- Mouse events (mousedown, mouseup, click)
- Pointer events
- Touch events
- Scroll to element
- Focus

**Статус:** ❌ НЕ РАБОТАЕТ - browser security блокирует все попытки

---

### 🛠️ Semi-manual тесты

#### 6. chrome_remote_test.py
**Назначение:** Браузерный тест с паузами для ручных действий

**Что делает:**
- Открывает Chrome
- Просит пользователя авторизоваться
- Просит открыть чат с ботом
- Автоматически отправляет команды
- Пытается кликнуть кнопки

**Статус:** 🛠️ ПОЛЕЗЕН для debugging, но требует участия пользователя

---

#### 7. auto_click_buttons.py
**Назначение:** Эмуляция кликов по кнопкам через Bot API

**Что делает:**
- Получает chat_id из последних updates
- Отправляет текстовые команды от имени пользователя
- **НЕ кликает inline кнопки** (отправляет callback_data как текст)

**Ограничения:**
- Не может симулировать реальные callback_query
- Только текстовые команды

**Статус:** 🛠️ РАБОТАЕТ как workaround, но не тестирует реальные кнопки

---

#### 8. auto_test_with_session.py
**Назначение:** Автоматический тест с предварительным запуском Chrome

**Что делает:**
- Проверяет запущен ли Chrome
- При необходимости запускает
- Подключается и выполняет тесты

**Статус:** 🛠️ В РАЗРАБОТКЕ

## 🎯 Рекомендации по тестированию

### Для проверки логики бота
```bash
python3 test_bot_logic.py
```
✅ Лучший вариант - быстро, надёжно, не требует браузер

### Для проверки что бот онлайн
```bash
python3 final_check.py
```
✅ Проверяет реальный бот через API

### Для manual UX testing
1. Запусти Chrome с сессией:
   ```bash
   python3 launch_chrome.py
   ```

2. Открой бота: https://web.telegram.org/k/#training_dag_run_bot

3. Тестируй вручную - inline кнопки работают только с реальными кликами

## ❌ Что НЕ работает

### Browser automation для inline кнопок
**Проблема:** Browser security блокирует programmatic callbacks

**Попытки решения:**
- JavaScript clicks ❌
- ActionChains ❌
- Mouse/Pointer/Touch events ❌
- Разные версии Telegram Web (/k/, /a/) ❌

**Вывод:** Полностью автоматическое тестирование inline кнопок через браузер НЕВОЗМОЖНО

**Альтернативы:**
1. ✅ Unit-тесты через mock (test_bot_logic.py)
2. ✅ Manual testing в реальном браузере/приложении
3. 🔧 Bot API симуляция (частично)
