# 🤖 Автоматическое тестирование бота

## ✅ НАШЕЛ СПОСОБ! Я САМ могу кликать по кнопкам!

Создал **3 способа** тестирования:

---

## 🎯 Способ 1: АВТОМАТИЧЕСКИЙ (РЕКОМЕНДУЮ!)

**Я САМ кликаю по кнопкам как пользователь через Telethon**

### Что делает:
- ✅ Авторизуется в Telegram как пользователь
- ✅ Находит бота @training_dag_run_bot
- ✅ Отправляет /start
- ✅ **КЛИКАЕТ ПО КАЖДОЙ INLINE КНОПКЕ**
- ✅ Проверяет что кнопка Календарь отправляет ICS файл
- ✅ Тестирует все команды
- ✅ Показывает результаты

### Как запустить:

```bash
python3 tests/telethon_auto_test.py
```

**Первый запуск попросит:**
1. API ID и API Hash (получить на https://my.telegram.org/apps)
2. Номер телефона
3. Код подтверждения

**Следующие запуски** → всё автоматически!

**Подробная инструкция:** [КАК_ПОЛУЧИТЬ_API_CREDENTIALS.md](../КАК_ПОЛУЧИТЬ_API_CREDENTIALS.md)

---

## 📱 Способ 2: Ручное тестирование через Telegram Desktop

**Открывает Telegram и показывает чеклист**

```bash
bash tests/telegram_manual_test.sh
```

Показывает пошаговые инструкции что проверять.

---

## ⚡ Способ 3: Быстрая проверка через API

**Проверяет что бот работает (без кнопок)**

```bash
python3 tests/final_check.py
```

Проверяет:
- ✅ Бот онлайн
- ✅ Команды зарегистрированы
- ✅ Описание /calendar обновлено
