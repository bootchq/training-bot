# Получение Groq API ключа (бесплатно)

**Groq** — бесплатный AI сервис с быстрой инференсией. Используется для AI-советов после тренировок.

---

## Шаг 1: Регистрация на Groq

1. Открой https://console.groq.com
2. Нажми **Sign Up** (регистрация)
3. Войди через Google аккаунт (bootchq@gmail.com)

---

## Шаг 2: Создание API ключа

1. После входа откроется Groq Console
2. В левом меню нажми **API Keys**
3. Нажми **Create API Key**
4. Задай имя: `training-bot`
5. Скопируй ключ (начинается с `gsk_...`)

⚠️ **Важно:** Ключ показывается только один раз. Сохрани его сразу.

---

## Шаг 3: Добавление ключа

### Локально (.env файл)

```bash
GROQ_API_KEY=gsk_ваш_ключ_здесь
```

### Railway (веб-интерфейс)

1. Открой Railway проект: https://railway.com/project/acf22966-f165-4e4d-a9ba-ce2efef63129
2. Выбери сервис
3. Вкладка **Variables**
4. Нажми **+ New Variable**
5. Добавь:
   ```
   GROQ_API_KEY=gsk_ваш_ключ_здесь
   ```
6. Railway автоматически перезапустит бота

---

## Шаг 4: Проверка работы

После настройки:

1. Открой Telegram → твой бот
2. Выполни `/sync` (синхронизация тренировки)
3. Отправь опрос самочувствия (симулируй или дождись вечера)
4. Должен прийти AI совет после опроса

---

## Лимиты Groq (бесплатный план)

- **Модель:** llama-3.1-70b-versatile
- **Лимит:** ~14,400 запросов/день (бесплатно)
- **Скорость:** ~300 токенов/сек (быстрее Claude)
- **Макс токенов:** 8,000 на запрос

Для бота с лимитом 100 запросов/день на пользователя — более чем достаточно.

---

## Альтернативы (если нужно)

Если Groq не подходит, можно использовать:

1. **OpenAI** (платно, ~$0.002 за запрос)
   - Переменная: `OPENAI_API_KEY`
   - Нужно обновить код в `consultant.py`

2. **Claude** (платно, ~$0.003 за запрос)
   - Переменная: `ANTHROPIC_API_KEY`
   - Откатить коммит с Groq

## Troubleshooting

### Ошибка "Invalid API key"
- Проверь что ключ начинается с `gsk_`
- Убедись что скопировал весь ключ полностью
- Попробуй создать новый ключ

### Ошибка "Rate limit exceeded"
- Это значит превышен лимит запросов
- Увеличь интервал между запросами
- Или подожди до следующего дня (лимит обновляется)

### AI советы не приходят
- Проверь логи Railway: есть ли ошибки от Groq
- Убедись что `openai` библиотека установлена
- Проверь что переменная `GROQ_API_KEY` установлена
